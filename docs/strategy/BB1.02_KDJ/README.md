## 策略条件

| 条件 | 参数 | 说明 |
|------|------|------|
| 大盘弱市 | ≥70% | 当日MA20下方个股比例 |
| 个股RSI | <20 | 14日RSI near_oversold |
| 布林带 | close ≤ boll_lower × 1.02 | 价格触及下轨附近 |
| KDJ | K < 20 或 J < 0 | KDJ超卖过滤 |
| 基本面 | TOP500 | PIT滚动打分 |
| 一字板 | 排除 | open=close=high=low |
| 流动性 | volume > 10000 | 排除极低流动性 |

**信号函数**：`signal_rsi_bb_kdj`（RSI + BB + KDJ 联合过滤）
