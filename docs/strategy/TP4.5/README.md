# TP4.5（止盈4.5%）

> 策略手册 | 正式策略 | 更新 2026-05-12

---

## 策略条件

| 条件 | 参数 | 说明 |
|------|------|------|
| 大盘弱市 | ≥40% | 当日MA20下方个股比例（阈值较低） |
| 个股RSI | <20 | 14日RSI低于20 |
| 布林带 | close ≤ boll_lower × 1.00 | 价格触及或穿透下轨 |
| 放量 | ≥1.1倍 | 当日成交量/5日均量 |
| 基本面 | TOP800 | PIT滚动打分 |
| 一字板 | 排除 | open=close=high=low |
| 流动性 | volume > 10000 | 排除极低流动性 |

---

## 交易规则

| 规则 | 参数 |
|------|------|
| 买入 | T+1开盘价 |
| 止损 | -3.5%（T+2起按收盘检查） |
| 止盈 | +4.5%（T+2起按收盘检查） |
| 持有 | 最多5天，第6天收盘卖出 |
| 仓位 | 每笔10% |
| 成本 | 双边0.30% |
